# 长廊 · 三支蜡烛

第一人称 3D 恐怖迷宫。手机横屏、虚拟摇杆，在黑暗的长廊里找三支蜡烛，
出口会在最后一支蜡烛点燃时打开——但那样东西也醒了。

## 玩法

- **左半屏**：按住拖动 = 移动（虚拟摇杆，按哪儿就在哪儿出现）
- **右半屏**：滑动 = 转头
- **拾**：靠近蜡烛/出口时拾取、通过
- **跑**：跑得快，但会喘（体力条），而且脚步声会把它引过来
- **手电**：开关手电，关掉不容易被发现，但你也看不清
- **⌖**：短暂提示最近的目标方向

三支蜡烛全部拿到 → 出口亮起绿光 → 走到出口即可逃出。

## 操作（桌面浏览器调试）

WASD 移动，鼠标拖动转视角，Shift 跑，F 手电，E 拾取，Esc 暂停。

## 技术

- 纯静态：`index.html` + ES Module，无需构建
- three.js 0.160（本地 `vendor/`，不依赖 CDN）
- 迷宫、墙体、贴图、音效全部程序化生成，无外部素材
- 怪物用 BFS 在走廊里追你；视线判定基于格子 Bresenham

## 本地跑

```bash
python3 -m http.server 8099
# 打开 http://127.0.0.1:8099/
```

## 部署

推送到 GitHub，Settings → Pages → 选 `main` 分支根目录即可，
地址形如 `https://<用户名>.github.io/<仓库名>/`。
